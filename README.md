# Theory-Converter-Automata-Formal-Languages-



A Java desktop application that converts between formal-language representations and helps students understand them visually.
Features
Input types: Regular Expression, DFA, NFA, CFG (regular grammar), and English phrase
Converts the input to the other forms: DFA, NFA, regex, and CFG
Draws the DFA and NFA graphs
Generates example strings accepted by the language
Simulates a test string step by step
Tech Stack
Java, Swing, Gradle
How to Run
Open the project in IntelliJ, set the Project SDK, and run src/main/java/com/theoryconverter/Main.java.
